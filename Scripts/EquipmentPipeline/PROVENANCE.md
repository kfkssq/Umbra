# M5 sample provenance

These 10 rigid low-poly fixtures and their icons are generated by `generate_samples.py`
for this Umbra project from box geometry and a deterministic orthographic rasterizer.
No third-party mesh, texture, screenshot, or character skeleton is used in these source files.
Units are centimeters; source axes are X/Y horizontal, Z up. Icons are 128×128 RGBA.

The fixtures are test geometry, not production art or certified wearable equipment.
The sword definitions reference the project's existing test weapon profile, and all definitions
reference the M3 generation profile. Those gameplay references do not transfer source mesh provenance.
This record does not certify the origin or redistribution rights of any existing project assets.

Authoring recipe/version: `generate_samples.py`, M5 initial version, 2026-10-30.
The manifest records SHA-256 of each generated OBJ/PNG. Material appearance, collision fit,
icon readability and any future skeleton compatibility require separate review.
